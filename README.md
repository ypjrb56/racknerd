## 免备案主机为什么不用备案？

备案是针对中国大陆服务器的监管要求：在境内提供公开访问的网站和网络服务，必须先完成备案；而美国、德国、新加坡等许多国家和地区并不强制类似流程。服务器在境外，自然就不在 ICP 备案的适用范围内——这就是“免备案”的全部原理，跟主机贵不贵、大厂还是小厂都没有关系。

有个容易踩坑的细分品类要单独提：**“国内免备案空间”**。以亿速互联的产品页为例，它宣称使用国内多线 BGP 机房，通过自主研发的映射技术把图片、JS 等静态资源放到国内 CDN 加速，实现“免备案还享受国内的打开速度”。这类方案的实现原理各商家说法不一，而监管层面对境内公开服务的要求是明确的。买之前把实现方式和合规风险问清楚，比只认“国内机房、还免备案”这几个字重要。

## 免备案主机省了什么，多付了什么？

省的是备案的时间和不确定性；代价集中在四件事上，买前心里得有数。

好处是：买完直接解析域名上线，不用等备案；数据中心遍布全球，可以选离访客近的节点；没有国内虚拟主机常见的电信、网通互访问题。

代价是：

- 封禁风险。监管部门无法直接管理境外主机上的网站，会通过屏蔽 IP 或域名的方式限制大陆用户访问。虚拟主机遇到这种情况基本只能被动接受，VPS 用户相对主动——比如 Vultr 的做法是删掉机器重新开一台就换了 IP，多数 VPS 服务商也有类似机制。
- 售后。部分境外服务商本地化服务弱、有时差，小型服务商还有关停风险。
- 速度。访问速度受地理距离影响，部分地区会明显偏慢。
- 支付。境外服务商支持的支付方式可能有限，不如国内便利。

还有一条容易被忽略：主机所在地政策不同，对网站内容的限制也不同，建站前先确认内容符合当地规定。

## 常见问题

**免备案主机会被封吗？**
有可能。监管方式是屏蔽 IP 或域名，限制大陆用户访问。这也是选 VPS 的一个实际理由：IP 被封后可以重装或更换，比共享环境主动得多。

**国内访问速度会很慢吗？**
看线路和距离。香港 CN2 直连、美国西岸的优化线路延迟相对可控；不少方案还会配国内 CDN 加速图片、JS 等静态资源。下单前先用商家提供的演示 IP 或测试地址实测一下。

**大陆服务器可以不备案吗？**
不可以。境内提供公开访问的网站和服务必须备案，免备案只适用于服务器在境外的场景。

**RackNerd 的服务器要备案吗？**
不需要，服务器在美国，不涉及 ICP 备案。不过“免备案”不等于没有约束，内容要符合主机所在地法律，也存在被屏蔽的可能。
